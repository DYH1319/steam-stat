# Steam Stat 最终形态 UI 清单

> 来源：2026-10-24 多轮需求访谈（UI 篇）。功能篇见 [feature-vision-261024.md](feature-vision-261024.md)。

**一句话风格：** 保留多彩渐变的活力，但色彩统一由主题色派生；大量使用游戏美术素材，营造「游戏感」；密度、导航、动效、外观都允许用户自定义。

**标记说明：** `[已有]` 现状保持。`[改进]` 现状需要调整。`[新增]` 新 UI 能力。

---

## 一、视觉风格与色彩

- `[已有]` 多彩渐变风格（统计卡片、彩色信息块），继续打磨细节。
- `[改进]` **所有颜色由主题色派生**：
  - 统计卡片的渐变改为由主题色派生的多个色相组成，换主题色时卡片一起变。
  - 图表色板也由主题色生成，取代现在「每张图一种鲜艳色加发光」的做法。
- `[已有]` 浅色/深色/跟随系统，默认跟随系统，**两套主题同等打磨**。
- `[新增]` 大量使用游戏美术素材：
  - 列表和图表图例带游戏小图标。
  - 详情页使用全宽横幅。
  - 仪表盘可以放封面墙。
  - 素材要做本地缓存，并提供占位图，保证离线和国内网络下也不会出现破图。

## 二、个性化外观

- `[已有]` 9 种预设主题色、圆角系数、界面缩放。
- `[新增]` 取色器自定义任意主题色。
- `[新增]` 自定义背景图（游戏横幅或本地图片），配合模糊/毛玻璃材质。
- `[新增]` Windows 11 Mica/亚克力窗口材质（不支持的系统上自动回退）。
- `[新增]` 界面字体、数字等宽字体、全局字号可选。
- `[新增]` 信息密度切换：舒适/紧凑。

---

## 三、布局与导航

**1. 导航模式**
- `[改进]` 导航模式由用户在设置里切换，对应框架内置的 `menu.mode`：
  - 单栏侧边栏，即 `single`，是现状和默认值。
  - 窄图标栏加子菜单，即 `side`。
  - 顶部导航，即 `head`。

**2. 菜单按业务对象组织（取代现在「本地…」按数据来源命名的做法）**
- 概览：仪表盘、全局时间线。
- 游戏：游戏库（含本地已安装应用）、单游戏详情。
- 统计与报告：分主题的统计页、周报/月报/年度回顾。
- 成就。
- 好友。
- 账号：本地账号、Steam 登录与会话。
- 档案：存档、截图、资料变化。
- 工具：数据源、网络诊断、导入/导出/备份。
- 设置、关于。

**3. 恢复框架内置组件**
- `[新增]` 多标签页（Tabbar），可以同时打开多个游戏详情或好友档案。
- `[新增]` 面包屑，用在深层页面，比如「统计 → 游戏详情 → 会话」。
- `[新增]` 前进/后退按钮，支持鼠标侧键。

**4. 标题栏（全局元素）**
- `[已有]` Logo 和名称、明暗切换、窗口控制按钮。
- `[新增]` 中间放全局搜索入口（Ctrl+K 命令面板）。
- `[新增]` 正在玩游戏时，显示游戏图标和本次实时计时。
- `[新增]` Steam 连接状态圆点（在线/部分可用/离线），点击查看详情。
- `[新增]` 当前账号切换器：显示头像，下拉切换全局账号视角。
- `[新增]` 通知中心铃铛（见第八节）。

**5. 窗口**
- `[新增]` 游戏详情、好友档案、报告可以弹出为独立窗口，方便并排对比。
- `[新增]` 记住窗口位置、大小和最大化状态。
- `[新增]` 窄窗口响应式：自动收起侧栏，卡片重新排列（同时覆盖 Steam Deck 的 1280×800）。

---

## 四、关键页面

**1. 概览仪表盘**
- `[新增]` 完全自定义的拖拽小组件布局：提供一套默认布局，用户可以增删、拖拽、调整大小，可以保存多套布局。
- 小组件来源：今日/本周时长、正在运行、最近会话、最近成就、好友动态、历史上的今天、热力图、封面墙等。

**2. 单游戏详情页（Steam 商店页式）**
- `[新增]` 顶部是全宽游戏横幅、标题和关键数字。
- 下方分标签页：概览、会话、成就、好友、存档、截图。
- 标签页之间共享游戏上下文；可以弹出为独立窗口。

**3. 全局时间线**
- `[新增]` 三种视图可切换：
  - 垂直信息流：按天分组的卡片，无限滚动。
  - 日历视图：每个格子显示当天的游戏图标，点击展开当天详情。
  - 水平时间轴：可缩放拖动，会话、成就、好友各占一条轨道。

**4. 统计分析页**
- `[改进]` 从单页网格改为按主题分标签页：时长、作息、游戏、纪录、对比。
- 顶部筛选条在各标签页之间共享（账号、时间范围、排除应用）。

**5. 报告与回顾**
- `[新增]` 年度回顾和周报/月报都用全屏幻灯片形式：一屏讲一个亮点，带转场动画，可以翻页。
- `[新增]` 分享图生成：
  - 多套模板（长图、方形卡片、手机竖版）。
  - 自己勾选要放的统计模块。
  - 和主播模式、隐藏游戏联动，自动打码。
  - 一键复制到剪贴板，或保存为文件。

**6. 设置页**
- `[改进]` 改为左侧分类、右侧内容的布局（类似 VS Code/Windows 设置），带设置项搜索。
- 分类：通用、外观、密度与格式、导航、记录规则、网络、隐私、同步与备份、快捷键、通知、更新、实验/高级。

---

## 五、集合数据与表格

- `[新增]` 游戏、好友、账号等集合统一提供三种视图：网格封面、卡片、紧凑表格。可切换，并按页面记住选择。
- `[新增]` 表格高级能力：
  - 自定义列的显示和顺序，可调列宽，记住偏好。
  - 多条件组合筛选，可以保存为视图。
  - 批量选择后标记状态、加标签、导出、隐藏。
  - 右键菜单：打开详情、复制 ID、在 Steam 中打开、加入目标清单等。
- 大数据量（1000 多个游戏、500 多个好友、数万条会话）使用虚拟滚动。

## 六、数字、时间与格式

- `[新增]` 时长格式全局可选：`133.9h`、`133h 55m` 或 `5天 13小时`。
- `[新增]` 默认显示相对时间（如「3 小时前」），悬停显示完整日期时间。
- `[新增]` 统计卡片数字从 0 滚动到目标值（受动效开关控制）。
- `[新增]` 可设置一周从周一还是周日开始、日期格式，以及**一天的分界点**（如凌晨 4 点前算前一天，避免熬夜的会话被拆到两天）。

## 七、图表

- `[改进]` 色板由主题色生成，同一个游戏在同一视图内颜色一致。
- `[新增]` 所有图表的通用交互：
  - 单图全屏放大。
  - 单图导出 PNG 或 CSV。
  - 同一数据在饼图、柱状图、矩形树图之间切换。
  - 长时间趋势图支持框选缩放时间轴（dataZoom）。
- `[改进]` 图表联动和下钻（见功能篇）。

## 八、反馈与状态

- `[改进]` 空状态使用插画，并给出下一步操作按钮（去登录、去开启检测、去导入基线）。
- `[改进]` 加载时用骨架屏，取代整页 loading。
- `[新增]` 通知中心：标题栏铃铛汇总历史通知（里程碑、报告、异常），可以标记已读。
- `[新增]` 后台任务面板：同步、导入、备份、成就拉取等长任务的进度，可以取消。
- `[新增]` 统一的数据新鲜度标识：每个数据块角落显示数据来源和「X 分钟前更新」，取代各页面各自的「上次刷新时间」。
- `[新增]` 升级后首次打开时弹出 What's New 更新日志。
- `[已有]` vue-sonner toast 提示，保持。

## 九、动效

- `[新增]` 默认使用较丰富的动效：页面转场、卡片悬停浮起、列表依次入场、图表动画。
- `[新增]` 设置里可以关闭，并自动跟随系统的「减少动态效果」（`prefers-reduced-motion`）。

## 十、键盘

- `[新增]` 全局快捷键：切换页面、刷新、搜索、前进/后退等，按 `?` 打开快捷键帮助面板。
- `[新增]` 快捷键可以在设置中重新绑定。
- `[已有]` 缩放快捷键（Ctrl + = / - / 滚轮）。

---

## 十一、技术一致性

- `[改进]` **统一到框架内置的 Fa\* 组件**：
  - 逐步移除 Ant Design Vue（目前用在标题栏等处）。
  - 优先使用 Fa\* 和 Reka UI，只在 Fa\* 没有覆盖的场景（大数据表格、复杂日期选择）保留 Element Plus。
- 遵守 AGENTS.md 的约定：不使用 `size="small"`；页面结构统一为 `FaPageMain` 加 `AppPageHeader`；不直接修改 `packages/components` 中的内置组件，需要扩展时先确认。
- 主题派生色板、密度、字体、动效开关要沉淀为全局 CSS 变量和 appearance store，避免每个页面各自实现。

## 十二、明确不在范围

- 极简低饱和风格、Steam 原生配色、只做深色主题。
- 色盲友好/高对比度模式（访谈中未选择，后续可以视反馈再加）。
- Steam Deck 游戏模式和手柄专用 UI（只做窄窗口响应式）。
- 桌面悬浮小组件（功能篇已排除）。

---

## 建议落地顺序

UI 改造应跟随功能优先级推进，不单独开一个大重构：

1. **随 P1-A/P1-B 先做的基础设施：**
   - 主题色派生色板（卡片和图表）、统一的数据新鲜度标识、骨架屏和插画空状态。
   - 时长和日期格式设置、相对时间。
   - 图表通用交互、按主题分标签的统计页、单游戏详情页。
   - 三视图集合组件和表格高级能力。
   - 新页面一律使用 Fa\*，同时逐步移除 Ant Design Vue。
2. **随 P2 做的门面体验：**
   - 菜单按业务对象重组，导航模式可切换，恢复 Tabbar、面包屑、前进后退。
   - 标题栏全局元素、通知中心、后台任务面板。
   - 拖拽仪表盘、全局时间线三视图、设置页改为左右分栏、快捷键体系、What's New。
3. **随 P3 及之后做：**
   - 年度回顾幻灯片和分享图。
   - 独立窗口、自定义背景和 Mica 材质、字体选择、密度切换的全量适配。

## 需要提前注意的几个问题

- **「全部可切换」的成本会成倍增加。** 导航有 3 种模式，密度有 2 档，明暗有 2 套，集合有 3 种视图。每增加一个维度，测试组合就翻倍。建议每个维度先保证默认值完美，其余选项做到「可用」即可。
- **背景图和 Mica 材质会影响文字对比度。** 需要给内容区加遮罩层或保证最低不透明度，否则多彩卡片在半透明背景上可读性会下降。
- **重度使用游戏素材时，素材加载要考虑网络。** 需要本地缓存、尺寸规范（图标、封面、横幅各一档）和失败占位图，并和功能篇的公共数据层、CDN 回退策略配合。
- **拖拽仪表盘和独立窗口在 Electron 里实现成本较高。** 独立窗口需要多个 BrowserWindow 共享 store 和 IPC 订阅，建议排在门面阶段的后段。
