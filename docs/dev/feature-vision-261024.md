# Steam Stat 最终形态功能清单

> 来源：2026-10-24 多轮需求访谈（功能篇）。UI 篇见 [ui-vision-261024.md](ui-vision-261024.md)。

**一句话定位：** Steam 数据档案馆。把 Steam 自己丢弃的数据（会话、好友动态、成就时间线、存档、截图、资料变化）永久存在本机，面向重度玩家和数据/统计爱好者。

**平台与边界：** Windows 加 Linux / Steam Deck，Linux 和 Deck 桌面模式做到功能可用，不做专门 UI。只做 Steam。数据永久保留。

**标记说明：** `[已有]` 现有功能，保持。`[改进]` 现有功能需要升级。`[新增]` 新功能。每个模块末尾标优先级：P1 最高，P4 最低。

---

## 一、游玩会话记录（核心资产）｜P1-A

**1. 会话采集**
- `[已有]` 定时检测运行中的 Steam 应用，记录应用、账号、开始/结束时间和时长。
- `[已有]` 可开关自动检测，检测间隔 1~60 秒可调。
- `[已有]` 退出时如果有应用在运行，可选「以当前时间结束」或「作废」。
- `[改进]` 异常退出、断电、蓝屏、进程被强杀时，用最后一次心跳时间自动补全结束时间。
- `[改进]` 电脑睡眠/休眠的时段不计入时长（监听系统电源事件，切分或扣除）。
- `[新增]` 挂机/AFK 检测：键鼠无操作超过 N 分钟标为挂机，统计时区分「有效游玩」和「挂机」。
- `[新增]` 前台/后台时长：记录游戏窗口在前台的时间。
- `[新增]` 记录自己的 Rich Presence 变化（地图、模式、关卡等，需要 CM 登录），挂在对应会话下。
- `[新增]` 设备标识：每条会话记录来自哪台电脑或 Deck，为多设备同步做准备。

**2. 会话管理**
- `[新增]` 会话明细列表：可搜索、筛选、分页的原始会话表格。
- `[新增]` 手动编辑、删除、合并会话（修正挂了一夜、合并断开的短会话）。
- `[新增]` 会话备注和标签，形成游戏日记（和谁一起玩、打到哪里）。
- `[新增]` 自动清洗规则：忽略短于 N 秒的会话，自动合并间隔很短的会话，排除指定应用（如 Wallpaper Engine、SteamVR）。

**3. 历史导入与对账**
- `[新增]` 导入 Steam 累计时长作为基线（来自 localconfig.vdf 或 CM），安装本软件之前的历史也能体现。
- `[新增]` 定期快照 Steam 官方累计时长，和本地会话对账，发现在其他设备上的游玩。
- `[新增]` 从其他统计工具或 CSV 导入会话数据。

## 二、统计与可视化｜P1-A

**1. 图表**
- `[已有]` 时长分布 TOP10、每日时长趋势、启动频率 TOP15、单应用最近 50 次时长趋势。
- `[已有]` 按用户和日期范围筛选，带快捷时间预设。
- `[新增]` GitHub 式年度热力图。
- `[新增]` 24 小时 × 星期作息热力图。
- `[新增]` 会话甘特图/时间轴（每天一行，显示每段游玩的起止）。
- `[新增]` 游戏生命周期曲线：从首次启动到弃坑的累计时长，可以叠加多个游戏对比。

**2. 分析**
- `[新增]` 单游戏详情页：汇总一个游戏的时长、会话、成就、存档、截图，以及哪些好友也在玩。
- `[新增]` 同比/环比（本周对上周、本月对去年同月），带趋势箭头。
- `[新增]` 个人纪录：最长连续游玩天数、最长连续休息、最长单次会话、最晚游玩等。
- `[新增]` 按类型、开发商、发行商、标签汇总时长（依赖游戏元数据和公共数据层）。

**3. 报告与回顾**
- `[新增]` 任意年份的年度回顾（类似 Steam Replay，但基于会话级数据）。
- `[新增]` 自动生成周报和月报。
- `[新增]` 分享图：一键生成长图或卡片，可以遮挡敏感信息。
- `[新增]` 历史上的今天。

**4. 交互**
- `[改进]` 图表联动和下钻：点击某天或某个游戏，自动筛选其他图表和明细。
- `[改进]` TOP N 数量和聚合粒度（小时/天/周/月）可调。
- `[新增]` 排除或只看指定应用。
- `[新增]` 自定义仪表盘：拖拽、增删图表卡片，可保存多套布局。

## 三、Steam 登录与 CM 会话｜P1-B

- `[已有]` 账号密码、扫码、已保存凭证三种登录方式，支持 Steam Guard（验证码或手机确认）。
- `[已有]` 多账号同时在线，可设置在线状态，可退出登录。
- `[已有]` 凭证用 DPAPI 加密保存；按错误类型决定重连策略，凭证失效时提示重新认证。
- `[已有]` CM 数据源页：会话状态、重连次数、错误码，以及已保存凭证的管理。
- `[已有]` 全局在线/部分可用/离线三种状态，离线时展示本地快照。
- `[改进]` **实验性功能全部转正，默认显示**。未登录时菜单置灰，并引导去登录。
- `[改进]` Linux 上的凭证存储要实现 libsecret 版本。

## 四、好友档案｜P1-B

- `[已有]` 好友列表、在线状态、正在玩的游戏、等级、上次在线时间。
- `[已有]` 手动选择要追踪的好友（**保持手动选择**），记录在线状态、游戏、昵称、Rich Presence 的变化。
- `[已有]` 状态变化记录：按类型和好友筛选，可清空。
- `[新增]` 好友个人档案页：在线作息热力图、常玩游戏排行、昵称变更历史。
- `[新增]` 根据观察到的状态变化估算好友在每个游戏上的时长。
- `[新增]` 一起游玩检测：你和好友同时在玩同一个游戏的时段，统计和谁一起玩得最多。
- `[新增]` 好友圈热门游戏：最近好友都在玩什么，以及趋势。
- `[新增]` 好友列表变化记录：加好友和删好友的时间（谁删了我）。
- `[新增]` 和好友完整对比：游戏库交集/差集、共同游戏时长、成就对比。

## 五、成就档案｜P1-B

- `[已有]` 按账号查看成就概览，进入单个游戏看详情（已解锁/未解锁、隐藏成就、解锁时间、全球解锁率、进度值）。
- `[已有]` 成就 schema 用 schema_hash 做增量缓存，多语言文本直接来自 Valve；显示数据来源、新鲜度和诊断码。
- `[新增]` 跨游戏成就时间线和日历。
- `[新增]` 稀有成就墙，以及已解锁成就的稀有度分布。
- `[新增]` 完美游戏和完成度统计：全成就游戏数、平均完成率、离全成就最近的游戏。
- `[新增]` 成就和会话关联：成就是在哪次会话、第几个小时解锁的，以及解锁速度分析。
- `[新增]` 成就目标清单：把想拿的成就加入清单，在应用内跟踪。
- `[新增]` 成就攻略外链（Steam 社区指南、搜索引擎）。

## 六、游戏库（档案视角）｜P1-B 收尾，可延后到 P2

- `[已有]` 自有库、家庭共享库、愿望单；封面/列表视图；按名称、时长、最后游玩、AppID、成就进度排序。
- `[改进]` 定位从「库浏览」改为「档案视角」：入库时间、积压程度、库规模增长曲线。
- `[新增]` 积压库/未启动清单：买了从没玩或玩了不到 1 小时的游戏，附统计。
- `[新增]` 每小时成本：用户手动录入或导入购买价格，计算每小时花费（不涉及市场价）。
- `[新增]` 游戏状态标记：在玩/通关/弃坑/想玩，可记录通关日期和个人评分。

## 七、本地数据（用户、应用、数据源）

**1. 本地用户页**
- `[已有]` 本机登录过的账号，显示 SteamID、AccountID、账号名、昵称、最近登录。
- `[已有]` 双击切换账号，可选登录状态，或以离线模式启动。
- `[已有]` 打开个人资料、SteamDB、userdata 目录。
- `[新增]` 账号卡片上直接显示该账号本周时长和最近在玩。
- `[新增]` 从托盘快速切换账号（见第九节）。

**2. 本地应用页**
- `[已有]` 已安装/运行中的应用、安装目录、磁盘占用（含实际占用）、多个库目录。
- `[新增]` 磁盘占用可视化：按库目录和游戏的矩形树图，显示剩余空间。
- `[新增]` 「装了不玩」清理建议：结合会话数据，列出 N 天没玩且占用大的游戏。
- `[新增]` 快捷操作：通过 `steam://` 协议启动游戏、验证完整性、打开商店页（实际操作交给 Steam 执行）。

**3. 数据源页**
- `[已有]` 本地数据源健康检查（注册表、各类 VDF/ACF、后台任务），可调轮询间隔。
- `[已有]` 页面依赖的数据源缺失时，路由守卫拦截，菜单置灰。

## 八、新的档案类型｜P4

- `[新增]` 存档备份：定位存档目录，定期快照，保留版本历史。**只读，绝不写回**。
- `[新增]` 插件化存档解析：先在仓库内置少量解析器，再开放 WASM 沙箱插件给社区贡献。解析器只产出结构化数据，由统一的渲染器展示。
- `[新增]` 截图档案：索引 Steam 截图目录，按游戏和日期浏览，关联到当时的会话。
- `[新增]` 自己的资料变化：昵称、头像、等级、徽章的历史。

## 九、首页、托盘与通知｜P2

- `[改进]` 启动主页可选（已有），默认值改为新的仪表盘。
- `[新增]` 概览仪表盘：今日/本周时长、正在运行、最近会话、最近成就、好友动态、历史上的今天。
- `[新增]` 独立的全局时间线页：我的会话、成就、好友变化、截图按时间混排。
- `[改进]` 丰富托盘菜单（目前只有「退出」）：当前游戏和今日时长、暂停/恢复记录、快速切换账号、快速打开各页面。
- `[新增]` 托盘悬停卡片，显示今日摘要。
- `[新增]` 系统通知：周报/月报/年报生成；里程碑（如某游戏累计 100 小时、打破个人纪录）；数据源或登录异常（检测任务停止、CM 需要重新认证，避免数据断档）。

## 十、数据导出、备份与同步｜P3

- `[已有]` SQLite 本地存储；数据库迁移前自动备份 `steam-stat.bak`。
- `[新增]` 导出 CSV/Excel（会话、好友记录、成就等）。
- `[新增]` 导出完整 JSON，用于迁移或二次开发。
- `[新增]` 一键手动备份和恢复。
- `[新增]` 多设备同步，三种后端都用端到端加密：
  - 自带存储：本地文件夹、WebDAV、S3，开源免费。
  - 官方托管云：付费，是 Open Core 的商业化点。
  - **Steam 凭证永远不参与同步。**
- `[新增]` Public Data 公共数据层：用 GitHub 加 CDN 分发成就 schema 和游戏元数据（类型、标签、开发商），减少请求次数，国内也能访问，为按类型汇总时长提供数据。

## 十一、网络、隐私与易用性（跟随各优先级推进）

- **网络**
  - `[新增]` 自定义 HTTP/SOCKS 代理。
  - `[新增]` 国内网络优化模式：优先走 CM/CDN，使用 WebSocket CM，延长超时。
  - `[新增]` 网络诊断页：各端点是否可达、延迟、最近错误。
- **隐私**
  - `[新增]` 主播/打码模式：一键隐藏账号名、SteamID、好友昵称。
  - `[新增]` 隐藏指定游戏：不出现在统计、报告和分享图里。
  - `[新增]` 数据库加密。
- **易用性**
  - `[已有]` 中文/英文；浅色/深色/跟随系统；9 种主题色；圆角和缩放可调。
  - `[已有]` 开机自启、静默启动、关闭行为可选、自动更新。
  - `[新增]` 全局搜索/命令面板（Ctrl+K），可搜游戏、好友、成就、页面。
  - `[新增]` 首次启动引导：检测 Steam、导入基线、说明隐私政策、可选登录。

## 十三、明确不做（范围之外）

- 原有 Non-goals 继续有效：不做 Steam 客户端替代品，不碰库存/饰品/市场，不做任何修改 Steam 数据的功能，不上传明文数据。
- 访谈中未选择的项目：
  - 非 Steam 游戏或任意进程的监测
  - 时长目标、防沉迷、深夜提醒这类「干预型」功能
  - 好友上线通知、成就解锁通知
  - 免登录读取本地成就缓存
  - 下载流量记录、创意工坊统计
  - 桌面悬浮组件、低资源后台模式
  - 账号备注、账号桌面快捷方式
  - 本地 HTTP API、对外文档化 SQLite schema
  - 应用锁、更多界面语言、Deck 手柄 UI、文档站点、使用量遥测
  - 自动定期备份、自定义数据目录、数据清理工具

## 建议路线

1. **P1-A 会话与统计加深。** 先补检测的可靠性（心跳补全、睡眠扣除、AFK、前台检测），再做明细编辑和清洗规则、基线导入，然后是新图表、单游戏详情页和报告。
2. **P1-B 实验功能转正。** 稳定 CM 后默认开启，然后做成就时间线和完成度、好友档案、一起游玩、对比、游戏库档案视角。
3. **P2 门面体验：** 仪表盘、全局时间线、托盘、通知、命令面板、首次引导。
4. **P3 数据可迁移：** 导出、手动备份、公共数据层、自带存储同步，最后才是托管云。
5. **P4 档案扩展：** 截图、资料变化、存档备份，然后是插件化解析。

## 需要提前注意的几个问题

- **范围很大。** 单人维护做不完全部，严格按 P 级推进，每个阶段都保证可以发版。
- **永久保留但没有自动备份，这有矛盾。** 档案馆最大的风险是数据库损坏或硬盘故障。建议至少在 P1 阶段做「每次启动保留最近 N 份快照」这样的轻量保护。
- **AFK 和前台检测在 Linux 上更难。** Wayland 不允许全局键鼠钩子和读取前台窗口，Linux 版可能要降级（只用 Rich Presence 或进程状态判断）。
- **托管云意味着要运营服务器**，还要承担合规和支付责任，和「单人长期维护」冲突最大。建议等自带存储同步稳定、确实有用户需求后再做。
- **数据库加密会让导出、调试和用户自救更麻烦。** 建议做成可选开关，并说明丢失密钥的后果。
